# Shared libraries the pux binary may link (DT_NEEDED), and how users get each.
# check_tar.sh fails the tarball build on any other library, so a new dependency
# cannot ship without being listed here and in tarball-README.txt (and in the
# install table of the top-level README.md).
#
#   baseline  present on any glibc 2.35+ desktop install
#   system    installed from the distribution; named in tarball-README.txt
#
# A third column of "documented" means tarball-README.txt must contain the exact
# soname the binary links (for example libsodium.so.23), so the guidance cannot
# drift from the library versions the release build was linked against.
#
# <soname glob>            <class>    <documented?>
